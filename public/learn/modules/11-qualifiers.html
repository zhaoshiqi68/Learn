把限定语读回去

§13 到结尾。两个缺席、三条被改写的旧观察、以及作者不许你推出的结论。

两个缺席，各带自己的因为

❝
§13.2

Code changes minute to minute, so pre-indexed embeddings are stale almost by construction.

这句解释的是代码检索。代码分钟级在变，预先做好的嵌入几乎一建好就过期。替代品是 ripgrep、glob、tree-sitter 和语言服务器。它没有说嵌入不能用来回忆对话。

框
框架缺席查的是清单和导入

做了两轮，包括后加的系统和 meta-harness。没追踪动态导入和编译后的发行包。作者说，若有一条没被看见的路径用了 LangChain，他们会惊讶，但不会震惊。

边
两处不能删的边界

OpenCode 用 Vercel AI SDK 做模型接入，不是编排。Aider 的 /help 可以可选安装 llama-index，只检索自己的文档。Hermes 里仅有的 LangChain 字符串，出现在教用户用向量库的 skill 文档里。

史
历史收场不是「他们落后了」

§14.2 的句子是：harness 没有采纳那些框架，它们取代了框架，并且自己变成了可以导入的库。

四月有三句，七月就地改了

1
耦合二分法

不是「只有厂商能做缓存和按模型写的提示」。多供应商系统可以用集中的条件代码买到其中一部分。只有服务端跟着模型发布改提示、客户端不用更新，还留在厂商自己那里。

2
规模意味着沙箱

这条相关破了。Hermes 和 OpenCode 是很大、但没有操作系统级隔离的反例。

3
协议只有两个角色

ACP 长出第三种用法：harness 托管别家 harness。A2A 网格仍然只有 Gemini CLI，这个「只有」没有被改掉。

💡
会过期的，和暂时还在的

工具数量、功能格子、版本钉按星期变。循环分类、七个子系统、两个缺席，到这一版还立得住。对着今天的仓库精读时，先对结构，再对某个文件还在不在。

收束句也不要读宽

❝
观察 12，§14.5

The competitive unit of the field is no longer the agent loop; it is the ecosystem surface around it.

竞争的单位从循环挪到了循环外面的生态表面：钩子、会话导入器、SDK、会托管别家 harness 的 ACP。这句没说循环对正确性不再重要，也没说谁的基准更高。Listing 3 仍然是教学脚手架：直接实现 10 条建议，兼容其余 8 条，shell=True，没有沙箱，用字符数估计 token，没有跑过基准。

这句转述把收束句推到了哪？

「论文证明循环已经不重要，接下来只做插件市场就行。」
