先核对「十一」和「三种循环」

§4 到 §6 最常见的误读，是把对照物算进样本，再把三种循环读成三选一。

样本那句话，主语要数全

四家厂商旗舰都在里面：Claude Code、Codex CLI、Gemini CLI，以及摘要里经常消失的 Mistral Vibe。开源一侧包括 OpenHands、Aider、Mini-SWE-Agent。快照钉在 2026 年 7 月能拿到的版本。

内
OpenClaw 在十一套里，但是离群点

它把自己写成个人助手网关，不是编程 Agent，没有原生改代码工具。放进来是为了检验「大家都在收敛」是不是只对编程 Agent 成立。Hermes 也是多通道网关，但自带编程工具，所以是普通成员。

外
Omnigent 不在十一套里

它把 harness 当成可替换部件，自己没有编辑循环。和十一套并列打七个子系统的分，是分类错误。

旧
纵向样本是四月那八套

七月才加入的 Hermes、Pi、OpenCode 不在「同一仓库钉两次」的差异里。三条旧观察后来被改写，改的是这八套的重读，不是这三套的前后对比。

⚠
Claude Code 的源码不是七月二进制

论文用的是 2026 年 3 月流传的非官方源码。七月发行二进制是 2.1.206，正文写明二进制可能已经不同。读到 Claude Code 的细节时，先记住这个版本差。

循环那句：三种形状，不是三选一

主体
动作–观察

九套的主循环是迭代式：组装提示，调用模型，执行工具，把观察追加回去。差别在并发、状态放在哪、什么叫做停。

唯一
反思形主循环

Aider 改完跑语法、编译和 flake8，失败再叫一次模型，默认最多三次。它是唯一把反思放进主循环的系统，不是第十一套里的普遍形态。

叠加
不是第三类

协调者–工作者叠在迭代循环上。Claude Code 和 Codex 里是规定好的，Hermes 要开配置。删掉「叠加」两个字，分类就错了。

误读
三选一

「每套系统恰好属于一种循环」不是论文的句子。十一套都是 ReAct 的变体。协调者可以和动作–观察同时存在。

有人说：「论文比较了 Hermes 从四月到七月的源码差异。」这句错在哪？
