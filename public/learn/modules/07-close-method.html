精读从限定语开始

概论把地图给过你了。从这里起，每句话只问三件事：它承诺什么，证据在哪，它拒绝什么。

对着 arXiv HTML 时，就用这三问

1
承诺

主语是谁，动词有多强。是「十一套都这样」，还是「到这一版还这样」。

2
证据

这句话靠源码、靠一张图，还是靠作者的猜想。搜导入和读一张图，不是同一种证据。

3
拒绝

紧挨着的限定语删掉之后，句子会变成另一篇论文。精读就是把那个限定语标回来。

📖
不转载全文

下面只引短句，方便你在 HTML 里定位。流通摘要里的 CC BY 4.0 没有在正文提取里核对到，引用以 arXiv 条目为准。

用开篇那句做一次示范

❝
§1

An agent is a model plus a harness. The model supplies the intelligence; the harness turns that intelligence into work.

加
第一分句是加法

Agent 等于模型加上 harness。不是「用外壳换掉模型」，也不是「外壳本身有智能」。

智
智能的位置在模型

supplies the intelligence。后面所有架构差异，论文都不拿来解释成「这个外壳更聪明」。

工
外壳把判断变成工作

turns that intelligence into work。工作是对仓库的动作、权限、恢复和停。这句话没说外壳能提高智力。

把说满的句子放回它丢掉的限定语

外壳从工具变成了平台
四百万行里零向量
没有任何框架
九十行实现了十八条

限定在 2026 年上半年的编程 harness，而且作者写成已经发生。不是所有 Agent，也不是永远。
