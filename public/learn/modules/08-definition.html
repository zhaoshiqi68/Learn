把定义的两句读完

§2 的定义很短。精读是看它把哪些东西算进「除模型以外」，又把哪些近义词推出去。

everything except the model

❝
§2.1

The harness is everything except the model: the runtime that couples an LLM to the world.

冒号后面把 everything 收成一件东西：把语言模型接到世界上的运行时。作者采用的核心来自 Macedo，再用七个子系统把它拆开：循环、模型接入、工具、记忆与上下文、安全、编排、扩展。定义文献暗示过这些部分，生产源码里此前没有被这样落地。

💡
七个子系统旁边还有两块横切表面

界面层是人用的：终端、旗标、IDE 协议、HTTP、SDK。会话基底是多个子系统共用的：记录、持久化、恢复、分叉。平台化的论证，很大一部分落在界面层上，而不是落在「循环更精致」上。

这句定义推出去的四个近义词

1
不是脚手架本身

脚手架是结构代码。Harness 是嵌进产品、交出去的运行时。一百行可以是脚手架；带权限和插件的产品才是 harness。

2
不是导入的框架

框架是开发者 import 的库。Harness 是人在里面工作的运行时。论文说这条界在 2026 年从两边同时在溶解，但定义本身还保持这个方向。

3
不是评测 harness

SWE-bench 包住 Agent 去跑题。Agent harness 包住模型让它行动。同一个词，包裹方向相反。

4
不是编排器

编排器在上面协调别的 harness，自己没有编辑循环。Omnigent 是关于 harness 的证据，把它算进十一套是分类错误。

这句话把定义收窄成了什么？

「Harness 就是提示词模板，再加上一份工具列表。」

Mini-SWE-Agent 用大约一百行实现了全部七个子系统。精读时，这句证明允许你留下哪一个结论？
