先把四个词分开

背景，不是论文结论。后面每句话都假定你分得清这些东西。

你已经见过这个场面

同一个模型，一个团队的 Agent 能连续改仓库，另一个跑三步就忘了任务，或者报错之后停在那里。论文认为先别换模型。

💡
这篇课的主语

外壳有个名字：harness。模型负责判断，harness 负责把判断变成对仓库的动作。

四个经常被叫成同一个词的东西

1
Harness

交付出去的运行时。Claude Code 是一件带权限和插件的产品，不只是一个循环。

2
脚手架

结构代码。Mini-SWE-Agent 的脚手架大约一百行。两者近义，但一个是骨架，一个是产品。

3
评测 harness

SWE-bench 包住 Agent 去跑题。Agent harness 包住模型让它去行动。方向相反。

4
Meta-harness

站在外面协调别的 harness。自己不写编辑循环。Omnigent 是这一层，不是十一套之一。
