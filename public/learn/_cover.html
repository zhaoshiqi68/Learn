这篇论文在说什么

一个 Agent 是模型加上把它接到世界上的运行时。作者读了十一套生产编程 Agent 的源码，大约四百万行，不打分。他们发现没有人用通用编排框架，也没有人用向量去搜代码。2026 年上半年，这层外壳从工具变成了平台。
